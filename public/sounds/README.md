# Scanner Sound Files

This directory contains audio files for the ticket scanner feedback:

- `success.mp3` - Played when a ticket is verified successfully
- `error.mp3` - Played when a ticket is invalid
- `warning.mp3` - Played when a ticket was already used

## Adding Sound Files

Replace these placeholders with actual audio files. Recommended sources:
- [Freesound.org](https://freesound.org) - Free sound effects
- [Mixkit](https://mixkit.co/free-sound-effects/) - Free sounds

Keep files under 50KB for fast loading.
